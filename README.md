# DIDIT INTEL v2

Static GitHub Pages directory with 384 imported OSINT4ALL bookmarks plus the original 12 starter resources (overlaps automatically deduplicated).

## Publish
Upload `index.html` to your existing `saucediditcompany/didit-intel` GitHub repository root, replacing the existing file. Optionally upload `resources.json` as a separately reusable catalog. GitHub Pages will redeploy.

## Source and limitations
The source JSON was collected from the *visible DOM* of https://start.me/p/L1rEYQ/osint4all. It reported 385 entries. 1 advertising/invalid/duplicate entries were excluded. Categories are approximate DIDIT INTEL groupings based on the extracted order, not verified original Start.me section headings. Descriptions explicitly indicate unverified listings. The links have not been visited or health-checked. Some may be broken, inappropriate, or obsolete. Do not assume this is the full OSINT4ALL collection. Attribution is shown in the website.

This static site does not need a backend or API key.
